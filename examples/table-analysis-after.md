# 10 月上旬渠道销售分析

## 口径

- 销售额：订单支付金额，未扣退款。
- 退款率：退款额 / 销售额。
- 缺失值：10-03 订单数缺失；10-06 退款额缺失。两项均保留原行，缺失值不参与对应均值计算。

## 核心数字

| 渠道 | 销售额 | 退款额 | 退款率 |
|---|---:|---:|---:|
| 自然流量 | 208,500 | 6,000 | 2.88% |
| 投放 | 329,400 | 14,000 | 4.25% |

## 发现

1. 投放渠道销售额更高，但退款率也更高（4.25% vs 2.88%）。
2. 10-09、10-10 两天投放退款额明显高于本旬其他投放日，建议检查这两天的投放素材和人群。
3. 10-03 订单数缺失，未纳入订单均值计算。

## 不能下的结论

- 不能判断退款率上升是投放导致的；目前只有相关，没有因果证据。
- 缺少去年同期退款率，无法判断 4.25% 是否异常。

## 复算方式

- 自然流量销售额：36000 + 40500 + 39000 + 45000 + 48000 = 208500。
- 自然流量退款额：1200 + 900 + 1500 + 1100 + 1300 = 6000。
- 投放销售额：63000 + 59400 + 66000 + 72000 + 69000 = 329400。
- 投放退款额：3200 + 2800 + 4100 + 3900 = 14000（10-06 缺失，未计入）。

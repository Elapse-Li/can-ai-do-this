# 岗位：会议纪要

> 判决：**试用期** · 适配分 **73/100** · 最后验证 2026-11

一句话：能分清“讨论过”和“决定了”，但人名、负责人和截止时间要自己核。

## 五维评分

| 维度 | 得分 | 依据 |
|---|---:|---|
| 重复度 | 20/20 | 每周多场，格式固定 |
| 可验收性 | 16/25 | 能回听录音核对，但逐句核很费时 |
| 出错代价 | 14/20 | 纪要错了会返工，少数会误导执行 |
| 数据敏感度 | 3/15 | 常含客户信息、报价、人事内容 |
| 标准明确度 | 20/20 | 有固定模板：决议、待办、分歧 |
| **合计** | **73/100** | **试用期：AI 出活，你挑刺** |

## 什么情况下用

- 会有录音或转写文本，且参会人同意录音。
- 会议目标明确，主要是同步信息、对齐排期、分配任务。
- 你需要的是“决议 + 待办 + 分歧”，不是逐字稿。

不适合：人事谈话、客户报价谈判、涉及法律责任的承诺、没有录音且全靠回忆的会。

## 最小输入

1. 录音转写文本（标明说话人更好）。
2. 参会人名单和会议目标。
3. 上次纪要，作为格式样例。
4. 明确哪些内容不能写进纪要。

## 工作流程

1. **转写**：用会议工具或转写工具出文本，先粗看一遍人名和专有名词。
2. **分段**：按议题切分，不要整篇丢进去。
3. **提取四类信息**：决议、待办、待确认、分歧。
4. **补全字段**：待办必须有负责人、截止时间、交付物；缺失就标 `【待确认】`。
5. **人工核对**：回听关键段落，确认没有把“可以考虑”写成“决定了”。
6. **发出前确认**：涉及对外承诺的，找当事人确认。

## 可直接复制的提示词

```text
你是一个会议纪要助手。下面是会议转写文本和参会人名单。

请输出：
1. 会议目标（1 句）
2. 已达成的决议（只写明确拍板的事）
3. 待办（负责人 + 截止时间 + 交付物）
4. 待确认（没有结论、需要下次再议的事）
5. 主要分歧（如有）

规则：
- 严格区分“讨论过”和“决定了”。没有明确拍板的，不要写成决议。
- 待办缺少负责人或时间时，写【待确认】，不要编。
- 保留反对意见，不要美化冲突。
- 不要总结成鸡汤，不要补充原文没有的信息。
```

## 试用期考核（验收清单）

- [ ] 每条“决议”都能在原文里找到明确拍板的句子。
- [ ] 每条待办都有负责人和时间；缺失的已标【待确认】。
- [ ] 没有把“讨论/建议/可以考虑”写成“决定”。
- [ ] 反对意见和分歧被保留，没有被“达成一致”抹平。
- [ ] 人名、公司名、产品名、数字与原文一致。
- [ ] 敏感内容已删除或替换。

## 常见翻车

| 翻车 | 表现 | 补救 |
|---|---|---|
| 把讨论当决议 | “可以考虑”变成“确定采用” | 回听原句，只保留明确拍板 |
| 编负责人 | 会上没人认领，纪要里出现名字 | 缺负责人一律标【待确认】 |
| 漏掉反对意见 | 只写“大家一致同意” | 要求单列“主要分歧” |
| 人名/术语错 | 转写把“李”写成“里” | 发出前对照参会人名单 |
| 过度总结 | 把具体排期写成“后续推进” | 待办必须带时间和交付物 |

## 数据红线

- 人事谈话、绩效、薪酬、组织调整。
- 客户报价、合同条款、未公开合作。
- 个人信息、电话、身份证号。
- 未公开的战略、融资、并购信息。

## 什么时候可以转正

连续 3 次会议纪要零事实错误，待办闭环率 100%，且不需要回听整段录音，可以把模板固化成固定工作流。涉及对外承诺的会议仍建议人工终审。

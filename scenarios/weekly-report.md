# 岗位：周报撰写

> 判决：**试用期** · 适配分 **79/100** · 最后验证 2026-11

一句话：能把碎片记录整理成结构，但数字、项目状态和下周计划必须自己核。

## 五维评分

| 维度 | 得分 | 依据 |
|---|---:|---|
| 重复度 | 20/20 | 每周一次，格式稳定 |
| 可验收性 | 16/25 | 结构可以检查，事实要回原始记录 |
| 出错代价 | 14/20 | 主要是返工，一般不会外溢 |
| 数据敏感度 | 9/15 | 内部进展，可能包含未公开信息 |
| 标准明确度 | 20/20 | 有固定模板和上周样例 |
| **合计** | **79/100** | **试用期：AI 出活，你挑刺** |

## 什么情况下用

- 每周都要写，格式基本固定。
- 手里有零散记录：聊天摘录、任务清单、会议笔记、提交记录。
- 领导只要求“说清楚进展和风险”，不要求文采。

不适合：需要替公司定调、写战略判断、或涉及未公开融资/人事信息的周报。

## 最小输入

1. 本周的零散记录（越原始越好，不用先整理）。
2. 上周周报，作为格式样例。
3. 下周已知的计划或节点。
4. 明确的禁区：哪些项目不能写、哪些数字不能出现。

## 工作流程

1. **脱敏**：去掉客户真名、未公开价格、人事信息。
2. **喂素材**：把记录、模板、下周计划一起给它。
3. **先让它列提纲**：确认哪些算“完成”，哪些只是“进行中”。
4. **再让它填内容**：要求所有不确定的信息标 `【待确认】`。
5. **人工核对**：数字、项目名、时间、负责人逐项回原始记录。
6. **删形容词**：把“赋能、闭环、抓手、显著提升”删掉，换成可验证的结果。

## 可直接复制的提示词

```text
你是一个周报整理助手。下面是我这一周的零散记录、任务清单和聊天摘录。

请按以下结构输出：
1. 本周完成（按项目分组，每条不超过 2 行）
2. 关键进展（只写有结果的事）
3. 风险与阻塞（没有就写“无”）
4. 下周计划（3-5 条，可执行）

规则：
- 只使用我给的材料，不要补充任何数字、人名、时间或项目状态。
- 材料里没有的信息，用【待确认】标出，不要猜。
- 不要写“赋能、闭环、抓手”这类词。
- 每条完成事项尽量带上可验证的结果（数量、链接、交付物）。
- 输出中文，语气平实。
```

## 试用期考核（验收清单）

- [ ] 每个数字都能在原始记录里找到出处。
- [ ] 项目状态与任务看板一致，没有把“进行中”写成“已完成”。
- [ ] 没有出现材料里不存在的人名、会议或时间。
- [ ] 下周计划是可执行的，不是“继续推进”这类空话。
- [ ] 没有未公开的客户名、价格、人事信息。

## 常见翻车

| 翻车 | 表现 | 补救 |
|---|---|---|
| 编进度 | 把“等反馈”写成“已交付” | 所有状态回看板核对 |
| 编数字 | 自动补一个“提升 30%” | 删除无出处数字，或标【待确认】 |
| 套话过多 | 满篇“赋能、闭环、抓手” | 要求它用“做了什么 + 结果”重写 |
| 泄露信息 | 带入客户真名、未公开报价 | 输入前脱敏；输出后搜一遍敏感词 |

## 数据红线

- 未公开的融资、并购、人事变动。
- 客户真名、合同金额、未发布价格。
- 密钥、密码、内部系统地址。
- 涉及个人的绩效、薪酬、健康信息。

## 什么时候可以转正

连续 4 周输出只需要改 10% 以内，且数字零错误，可以把“提纲 → 填充 → 自检”固化成固定模板或工作流。只要出现过一次编数字，退回人工核对。

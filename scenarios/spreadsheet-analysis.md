# 岗位：表格分析

> 判决：**试用期** · 适配分 **76/100** · 最后验证 2026-11

一句话：能算数、能解释，但口径要先定，结论要能追溯到具体的行和列。

## 五维评分

| 维度 | 得分 | 依据 |
|---|---:|---|
| 重复度 | 15/20 | 每周/每月都有，但不一定同口径 |
| 可验收性 | 25/25 | 数字能用公式、透视表复算 |
| 出错代价 | 14/20 | 分析错了会误导决策，但通常可追溯 |
| 数据敏感度 | 9/15 | 常含交易数据、客户信息 |
| 标准明确度 | 13/20 | 分析目标清楚，口径常要现定 |
| **合计** | **76/100** | **试用期：AI 出活，你挑刺** |

## 什么情况下用

- 数据是结构化的表格（CSV / XLSX），字段含义基本清楚。
- 你要的是描述性分析：汇总、对比、趋势、异常。
- 有明确的业务问题，比如“哪个渠道退款率高”。
- 你能用公式或透视表复算关键数字。

不适合：没有数据字典的黑箱表、需要因果推断的实验分析、涉及个人敏感信息且无法脱敏的数据。

## 最小输入

1. 表格文件，或脱敏后的样本。
2. 字段说明：每个字段是什么意思，口径是什么。
3. 分析目标：要回答哪几个业务问题。
4. 已知的数据问题：缺失、重复、口径变更。

## 工作流程

1. **先让它写分析计划**：字段理解、指标定义、口径、缺失值处理方式。
2. **人工确认口径**：这一步不能省，口径错了后面全错。
3. **再让它计算**：要求给出计算过程和结果。
4. **抽样复算**：用公式或透视表核对总数、均值、比例。
5. **让它解释异常**：异常值先查数据，再谈业务原因。
6. **人工定结论**：区分“数据显示”和“我推断”。

## 可直接复制的提示词

```text
你是一个数据分析助手。我会给你一张表和分析目标。

第一步，先不要计算，输出：
- 你理解的字段含义
- 你准备计算的指标和口径
- 数据里可能存在的问题（缺失、重复、异常值）

等我确认口径后，再执行分析。

输出规则：
- 金额按元保留整数，比例保留两位小数；同一张表里保持一致。
- 每个结论必须能追溯到具体列/行或计算过程。
- 区分“相关”和“因果”，不要说“导致”。
- 缺失值和异常值要单独说明，不要静默丢弃。
- 不确定的地方直接说“不确定”，不要编行业基准。
```

## 试用期考核（验收清单）

- [ ] 总数、均值、比例至少抽样复算过一遍。
- [ ] 缺失值和异常值的处理方式写清楚了，没有静默丢弃。
- [ ] 指标口径前后一致，没有中途换算法。
- [ ] 图表和数字对得上，坐标轴没有误导。
- [ ] 没有把相关性说成因果关系。
- [ ] 没有编造行业基准或外部数据。

## 常见翻车

| 翻车 | 表现 | 补救 |
|---|---|---|
| 算错 | 总额、均值、百分比对不上 | 用公式/透视表复算关键数字 |
| 口径漂移 | 两段分析用了不同分母 | 先固定口径，写进提示词 |
| 忽略缺失值 | 直接删行，样本量悄悄变少 | 要求单独报告缺失情况 |
| 相关当因果 | “投放导致退款率上升” | 改成“投放渠道退款率更高，原因待查” |
| 图表误导 | 截断坐标轴、混淆绝对值与比例 | 图表必须和表格数字互相验证 |

## 数据红线

- 客户名单、手机号、身份证号、地址。
- 未脱敏的交易记录、支付信息。
- 员工薪酬、绩效、健康信息。
- 未公开的财务数据、合同金额。

## 什么时候可以转正

连续 3 次分析零计算错误，口径固定，且能把“取数 → 清洗 → 计算 → 图表”固化成脚本或工作流。涉及对外决策的结论仍需人工签字。
